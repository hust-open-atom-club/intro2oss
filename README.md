# 开源软件通识课程

《开源软件通识》是华中科技大学开放原子开源俱乐部维护的线上教材。课程面向具备基础编程能力、但尚未系统参与开源的计算机类本科生，共 16 课时，按 8 次双课时组织。

课程遵循“以开源方式建设开源课程”的原则，目标是让学生从认识开源出发，最终完成一次真实、规范、可追踪的开源贡献。

## 学习成果

完成课程后，学生应当能够：

- 从软件类型、开发方式、协作模式和产业生态四个维度解释开源；
- 理解社区、企业、基金会、许可证与常见治理方式；
- 使用 Markdown、Git 和代码托管平台完成协作；
- 向真实开源项目提交贡献并响应评审意见；
- 复盘首次贡献，规划持续参与开源的路径。

## 课程安排

| 次数 | 主题 | 主要成果 |
|------|------|----------|
| 1 | 认识开源与项目启动 | 开源项目画像 |
| 2 | 历史与生态 | 项目生态角色分析 |
| 3 | 许可证与合规 | 许可证判断练习 |
| 4 | 社区文化与治理 | 贡献选题与提案 |
| 5 | 最小贡献工具链 | Markdown 与 Git 实验 |
| 6 | 平台协作流程 | 可评审的贡献草稿 |
| 7 | 真实贡献工作坊 | Issue、PR 或补丁 |
| 8 | 反馈响应与持续参与 | 贡献证据与复盘 |

完整安排见[课程大纲](docs/course/index.md)，项目要求见[真实贡献项目](docs/course/project.md)，评分办法见[成绩评定](docs/course/assessment.md)。

## 内容结构

- 第零章：通过故事和案例认识开放、共享与协作；
- 第一章：回答开源是什么、从何而来、为何重要以及如何参与；
- 第二章：理解生态、文化、治理、回报和法律合规；
- 第三章：掌握完成首次贡献所需的 Markdown、Git 和平台协作；
- 第四章：从一次贡献走向持续参与，认识维护者和社区领导路径；
- 拓展内容：Linux 工具、Git 进阶、Docker、QEMU 和邮件列表协作。

## 本地预览

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

默认预览地址为 <http://127.0.0.1:8000>。
