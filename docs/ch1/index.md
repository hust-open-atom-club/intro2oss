# 导览

本章按“是什么—从哪来—为什么—怎么做”的顺序展开，为后续章节的动手实践打基础。四节各有侧重，建议依次阅读，也可以先跳到最关心的一节。

**[第一节 什么是开源（What）](sec1/what-is-oss.md)**  
从日常使用的软件和几个关键故事入手，说明“开源”在不同语境下的多重含义：它既是一类源代码公开的软件，也是一种协作开发模式、一种创新机制和一个产业生态。读完后，你应当能够判断一个项目是否属于开源，并理解开源并不等于“免费”。

**[第二节 开源简史（History）](sec2/history-of-oss.md)**  
按时间顺序梳理开源运动的脉络：从自由软件运动与 GNU 计划，到 Linux、Apache 等项目的兴起和代码托管平台的演变，再到中国开源社区的发展轨迹。了解这段历史，有助于理解今天社区规则的由来。

**[第三节 为什么要开源（Why）](sec3/why-oss.md)**  
用一组课堂博弈游戏对比“抢存量”和“做增量”两种局面，讨论开源对个人、组织和整个行业的意义，同时承认现实中的不确定性与代价。这一节回答的是“值不值得做”，而不是“具体怎么做”。

**[第四节 怎么做开源（How）](sec4/how-to-oss.md)**  
区分狭义开源（软件代码开放）与广义开源（硬件、数据、教育、标准等），给出学生可以选择的参与渠道，并附上一份第一次贡献的操作清单。读完后，你应当能够找到适合自己的第一个入口。

本章的目标是帮助你建立对开源概念、历史、价值和实践路径的整体认知，为深入探索开源世界奠定基础。
