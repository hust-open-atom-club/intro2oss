# 🌐 第一章导览：开源简介

!!! abstract "章节概述"

    本章将系统性地揭开开源世界的神秘面纱，带你建立对开源的完整认知框架。

## 📋 四维认知框架

<div class="grid cards" markdown>

-   :material-help-circle:{ .lg .middle } __什么是开源（What）__

    ---

    通过日常软件实例（如浏览器、Linux）和关键故事（如 Linus 创建 Linux、Git 的诞生），深入剖析开源的多重内涵：

    - 作为**"软件类型"**（源代码开放、自由使用）
    - 作为**"开发模式"**（协作进化）
    - 作为**"创新模式"**（共享协作）
    - 作为**"产业生态"**（如云计算、Red Hat 商业成功）
    - 作为**"文化理念"**（共享、自由、透明）

    [:octicons-arrow-right-24: 开始学习](sec1/what-is-oss.md)

-   :material-history:{ .lg .middle } __开源简史（History）__

    ---

    纵览开源发展历程：

    - 国际开源运动的里程碑（GNU、Linux、Apache、GitHub 的兴起）
    - Stallman 与 GPL 的故事
    - 中国开源的发展轨迹（红旗 Linux 的起步、OpenEuler/OpenHarmony 等现代项目的崛起）

    全面展示开源的演进脉络。

    [:octicons-arrow-right-24: 回顾历史](sec2/history-of-oss.md)

-   :material-lightbulb-on:{ .lg .middle } __为什么要开源（Why）__

    ---

    从多个层面阐述开源的价值：

    | 层面 | 核心价值 |
    |------|---------|
    | 个人 | 学生实践平台、开发者成长、大神典范 |
    | 社区 | 加速全球协作创新 |
    | 企业 | Red Hat/MongoDB 等商业化模式 |
    | 国家 | 推动技术创新、保障自主性 |
    | 全人类 | 促进信息自由流通与共同进步 |

    [:octicons-arrow-right-24: 探索价值](sec3/why-oss.md)

-   :material-hammer-wrench:{ .lg .middle } __怎么做开源（How）__

    ---

    指导实践路径：

    - **狭义开源**：选择 GPL/MIT/Apache 等协议、代码托管平台操作
    - **托管平台演变**：从 SourceForge 到 GitHub/Gitee
    - **广义开源**：生态建设（文档、工具链、文化及非代码贡献）

## 🎯 学习路径建议

!!! tip "推荐学习顺序"

    我们建议你按照 **What → History → Why → How** 的顺序阅读本章：

    1. 先建立对开源的**基本认知**（What）
    2. 了解开源的**历史脉络**（History），理解它为何会产生
    3. 思考开源的**价值与意义**（Why），找到自己参与的动力
    4. 最后掌握**实践方法**（How），将知识转化为行动

!!! warning "常见误区"

    初学者容易将开源简单理解为"免费软件"或"把代码放到网上"。
    通过本章的学习，你将理解开源是一套包含**技术、法律、协作和文化**四个维度的完整制度。
