# 关于本课程

《开源软件通识》由华中科技大学开放原子开源俱乐部以开放协作方式建设，课程网站和教材源码托管在 [`hust-open-atom-club/intro2oss`](https://github.com/hust-open-atom-club/intro2oss)。

## 建设原则

- 以真实开源协作过程组织学习，而不是只讲解工具命令；
- 区分课堂必修与课外拓展，控制 16 课时的学习负担；
- 对事实、数据和案例标注来源与时间，定期检查过时内容；
- 接受文档、教学设计、案例、测试和站点功能等多种贡献；
- 尊重第三方作品的版权和许可证要求。

## 参与贡献

发现错误或希望补充内容时，请先阅读仓库中的 [`CONTRIBUTING.md`](https://github.com/hust-open-atom-club/intro2oss/blob/main/CONTRIBUTING.md)。小型修正可以直接提交 Pull Request；新增章节或大范围重构应先创建 Issue 讨论。

## 许可证

本课程仓库采用 MIT 许可证。引用的第三方文字、图片、代码和链接仍遵循各自的版权与许可证声明。
